# NDSS 2025

This list focuses on accepted papers about the security, privacy, safety, and trustworthiness of AI/ML systems. Papers were screened by title from the [NDSS 2025 official paper list](https://www.ndss-symposium.org/ndss2025/accepted-papers/) and then checked against their publicly available abstracts.

Each `Research question` and `What they did` line is one sentence. Method summaries are grounded in the abstract; if no public abstract was available, the entry says so explicitly instead of inferring a contribution from the title.

## 1. LLM and Agent Security

- [Generating API Parameter Security Rules with LLM for API Misuse Detection](https://www.ndss-symposium.org/ndss-paper/generating-api-parameter-security-rules-with-llm-for-api-misuse-detection/)
  - **Research question:** What LLM or agent attack surface, failure mode, or defense does “Generating API Parameter Security Rules with LLM for API Misuse Detection” investigate?
  - **What they did:** The authors present a new framework, named GPTAid, for automatic APSRs generation by analyzing API source code with LLM and detecting API misuse caused by incorrect parameter use.
- [Safety Misalignment Against Large Language Models](https://www.ndss-symposium.org/ndss-paper/safety-misalignment-against-large-language-models/)
  - **Research question:** What LLM or agent attack surface, failure mode, or defense does “Safety Misalignment Against Large Language Models” investigate?
  - **What they did:** Specifically, the authors investigate four research questions: (1) evaluating the robustness of LLMs with different alignment strategies, (2) identifying the most effective misalignment method, (3) determining key factors that influence misalignment effectiveness, and (4) exploring various defenses.
- [The Midas Touch: Triggering the Capability of LLMs for RM-API Misuse Detection](https://www.ndss-symposium.org/ndss-paper/the-midas-touch-triggering-the-capability-of-llms-for-rm-api-misuse-detection/)
  - **Research question:** What LLM or agent attack surface, failure mode, or defense does “The Midas Touch: Triggering the Capability of LLMs for RM-API Misuse Detection” investigate?
  - **What they did:** The authors propose an LLM-empowered RM-API misuse detection solution, ChatDetector , which fully automates LLMs for documentation understanding which helps RM-API constraints retrieval and RM-API misuse detection.

## 2. Backdoors, Poisoning, and Adversarial ML

- [AlphaDog: No-Box Camouflage Attacks via Alpha Channel Oversight](https://www.ndss-symposium.org/ndss-paper/alphadog-no-box-camouflage-attacks-via-alpha-channel-oversight/)
  - **Research question:** How does “AlphaDog: No-Box Camouflage Attacks via Alpha Channel Oversight” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors introduce AlphaDog, an Alpha channel attack, the first universally efficient targeted no-box attack, exploiting the often overlooked Alpha channel in RGBA images to create visual disparities between human perception and machine interpretation, efficiently deceiving both.
- [Automated Mass Malware Factory: The Convergence of Piggybacking and Adversarial Example in Android Malicious Software Generation](https://www.ndss-symposium.org/ndss-paper/automated-mass-malware-factory-the-convergence-of-piggybacking-and-adversarial-example-in-android-malicious-software-generation/)
  - **Research question:** How does “Automated Mass Malware Factory: The Convergence of Piggybacking and Adversarial Example in Android Malicious Software Generation” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors investigate piggybacked malware, a type of malware generated in bulk by piggybacking malicious code into popular apps, and combine it with adversarial example techniques.
- [BARBIE: Robust Backdoor Detection Based on Latent Separability](https://www.ndss-symposium.org/ndss-paper/barbie-robust-backdoor-detection-based-on-latent-separability/)
  - **Research question:** How does “BARBIE: Robust Backdoor Detection Based on Latent Separability” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors propose BARBIE, a backdoor detection approach that can pinpoint latent separability under adaptive backdoor attacks.
- [DShield: Defending against Backdoor Attacks on Graph Neural Networks via Discrepancy Learning](https://www.ndss-symposium.org/ndss-paper/dshield-defending-against-backdoor-attacks-on-graph-neural-networks-via-discrepancy-learning/)
  - **Research question:** How does “DShield: Defending against Backdoor Attacks on Graph Neural Networks via Discrepancy Learning” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** To tackle these challenges, the authors propose DShield, a comprehensive defense framework with a discrepancy learning mechanism to defend against various graph backdoor attacks.
- [LADDER: Multi-Objective Backdoor Attack via Evolutionary Algorithm](https://www.ndss-symposium.org/ndss-paper/ladder-multi-objective-backdoor-attack-via-evolutionary-algorithm/)
  - **Research question:** How does “LADDER: Multi-Objective Backdoor Attack via Evolutionary Algorithm” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** In particular, the authors formulate LADDER as a multi-objective optimization problem (MOP) and solve it via multi-objective evolutionary algorithm (MOEA).
- [Magmaw: Modality-Agnostic Adversarial Attacks on Machine Learning-Based Wireless Communication Systems](https://www.ndss-symposium.org/ndss-paper/magmaw-modality-agnostic-adversarial-attacks-on-machine-learning-based-wireless-communication-systems/)
  - **Research question:** How does “Magmaw: Modality-Agnostic Adversarial Attacks on Machine Learning-Based Wireless Communication Systems” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors further introduce new objectives for adversarial attacks on downstream applications.
- [Passive Inference Attacks on Split Learning via Adversarial Regularization](https://www.ndss-symposium.org/ndss-paper/passive-inference-attacks-on-split-learning-via-adversarial-regularization/)
  - **Research question:** How does “Passive Inference Attacks on Split Learning via Adversarial Regularization” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors introduce SDAR, a novel attack framework against SL with an honest-but-curious server.
- [PBP: Post-training Backdoor Purification for Malware Classifiers](https://www.ndss-symposium.org/ndss-paper/pbp-post-training-backdoor-purification-for-malware-classifiers/)
  - **Research question:** How does “PBP: Post-training Backdoor Purification for Malware Classifiers” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** Addressing this scenario, the authors introduce PBP, a post-training defense for malware classifiers that mitigates various types of backdoor embeddings without assuming any specific backdoor embedding mechanism.
- [RAIFLE: Reconstruction Attacks on Interaction-based Federated Learning with Adversarial Data Manipulation](https://www.ndss-symposium.org/ndss-paper/raifle-reconstruction-attacks-on-interaction-based-federated-learning-with-adversarial-data-manipulation/)
  - **Research question:** How does “RAIFLE: Reconstruction Attacks on Interaction-based Federated Learning with Adversarial Data Manipulation” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors show that users face an elevated risk of having their private interactions reconstructed by the central server when the server can control the training features of the items that users interact with.
- [Revisiting Physical-World Adversarial Attack on Traffic Sign Recognition: A Commercial Systems Perspective](https://www.ndss-symposium.org/ndss-paper/revisiting-physical-world-adversarial-attack-on-traffic-sign-recognition-a-commercial-systems-perspective/)
  - **Research question:** How does “Revisiting Physical-World Adversarial Attack on Traffic Sign Recognition: A Commercial Systems Perspective” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors conduct the first large-scale measurement of physical-world adversarial attacks against commercial TSR systems.
- [SafeSplit: A Novel Defense Against Client-Side Backdoor Attacks in Split Learning](https://www.ndss-symposium.org/ndss-paper/safesplit-a-novel-defense-against-client-side-backdoor-attacks-in-split-learning/)
  - **Research question:** How does “SafeSplit: A Novel Defense Against Client-Side Backdoor Attacks in Split Learning” expose, measure, or mitigate backdoor, poisoning, or adversarial risk in AI models?
  - **What they did:** The authors present SafeSplit, the first defense against client-side backdoor attacks in Split Learning (SL).

## 3. AI Privacy, Memorization, and Unlearning

- [A Method to Facilitate Membership Inference Attacks in Deep Learning Models](https://www.ndss-symposium.org/ndss-paper/a-method-to-facilitate-membership-inference-attacks-in-deep-learning-models/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “A Method to Facilitate Membership Inference Attacks in Deep Learning Models” investigate?
  - **What they did:** In this setting, the authors demonstrate a new form of membership inference attack that is strictly more powerful than prior art.
- [Black-box Membership Inference Attacks against Fine-tuned Diffusion Models](https://www.ndss-symposium.org/ndss-paper/black-box-membership-inference-attacks-against-fine-tuned-diffusion-models/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “Black-box Membership Inference Attacks against Fine-tuned Diffusion Models” investigate?
  - **What they did:** The authors propose the first scores-based membership inference attack framework tailored for recent diffusion models, and in the more stringent black-box access setting.
- [CENSOR: Defense Against Gradient Inversion via Orthogonal Subspace Bayesian Sampling](https://www.ndss-symposium.org/ndss-paper/censor-defense-against-gradient-inversion-via-orthogonal-subspace-bayesian-sampling/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “CENSOR: Defense Against Gradient Inversion via Orthogonal Subspace Bayesian Sampling” investigate?
  - **What they did:** The authors conduct comprehensive experiments across three different datasets and evaluate their defense against various state-of-the-art attacks and defenses.
- [Defending Against Membership Inference Attacks on Iteratively Pruned Deep Neural Networks](https://www.ndss-symposium.org/ndss-paper/defending-against-membership-inference-attacks-on-iteratively-pruned-deep-neural-networks/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “Defending Against Membership Inference Attacks on Iteratively Pruned Deep Neural Networks” investigate?
  - **What they did:** The authors propose a new framework WeMem to weaken memorization in the iterative pruning process.
- [Diffence: Fencing Membership Privacy With Diffusion Models](https://www.ndss-symposium.org/ndss-paper/diffence-fencing-membership-privacy-with-diffusion-models/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “Diffence: Fencing Membership Privacy With Diffusion Models” investigate?
  - **What they did:** The authors introduce a novel defense framework against MIAs by leveraging generative models.
- [I Know What You Asked: Prompt Leakage via KV-Cache Sharing in Multi-Tenant LLM Serving](https://www.ndss-symposium.org/ndss-paper/i-know-what-you-asked-prompt-leakage-via-kv-cache-sharing-in-multi-tenant-llm-serving/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “I Know What You Asked: Prompt Leakage via KV-Cache Sharing in Multi-Tenant LLM Serving” investigate?
  - **What they did:** Specifically, the authors introduce their attack, PROMPTPEEK, and apply it to three scenarios where the adversary, with varying degrees of prior knowledge, is capable of reverse-engineering prompts from other users.
- [Privacy-Preserving Data Deduplication for Enhancing Federated Learning of Language Models](https://www.ndss-symposium.org/ndss-paper/privacy-preserving-data-deduplication-for-enhancing-federated-learning-of-language-models/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “Privacy-Preserving Data Deduplication for Enhancing Federated Learning of Language Models” investigate?
  - **What they did:** The authors address the problem of deduplication in a federated setup by introducing a pioneering protocol, Efficient Privacy-Preserving Multi-Party Deduplication (EP-MPD).
- [Reinforcement Unlearning](https://www.ndss-symposium.org/ndss-paper/reinforcement-unlearning/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “Reinforcement Unlearning” investigate?
  - **What they did:** To tackle these challenges, the authors propose two reinforcement unlearning methods.
- [Scale-MIA: A Scalable Model Inversion Attack against Secure Federated Learning via Latent Space Reconstruction](https://www.ndss-symposium.org/ndss-paper/scale-mia-a-scalable-model-inversion-attack-against-secure-federated-learning-via-latent-space-reconstruction/)

- [URVFL: Undetectable Data Reconstruction Attack on Vertical Federated Learning](https://www.ndss-symposium.org/ndss-paper/urvfl-undetectable-data-reconstruction-attack-on-vertical-federated-learning/)
  - **Research question:** What privacy, memorization, extraction, or forgetting problem does “URVFL: Undetectable Data Reconstruction Attack on Vertical Federated Learning” investigate?

## 4. Deepfakes, Watermarking, and Content Provenance

- [Explanation as a Watermark: Towards Harmless and Multi-bit Model Ownership Verification via Watermarking Feature Attribution](https://www.ndss-symposium.org/ndss-paper/explanation-as-a-watermark-towards-harmless-and-multi-bit-model-ownership-verification-via-watermarking-feature-attribution/)
  - **Research question:** How does “Explanation as a Watermark: Towards Harmless and Multi-bit Model Ownership Verification via Watermarking Feature Attribution” address generated-content detection, attribution, authenticity, copyright, or provenance?
  - **What they did:** Motivated by this understanding, the authors design a new watermarking paradigm, $i.e.$, Explanation as a Watermark (EaaW), that implants verification behaviors into the explanation of feature attribution instead of model predictions.
- [VoiceRadar: Voice Deepfake Detection using Micro-Frequency and Compositional Analysis](https://www.ndss-symposium.org/ndss-paper/voiceradar-voice-deepfake-detection-using-micro-frequency-and-compositional-analysis/)
  - **Research question:** How does “VoiceRadar: Voice Deepfake Detection using Micro-Frequency and Compositional Analysis” address generated-content detection, attribution, authenticity, copyright, or provenance?
  - **What they did:** The authors propose a novel audio deepfake detection method, VoiceRadar, that augments machine learning with physical models to approximate frequency dynamics and oscillations in audio samples.

## 5. AI Safety, Alignment, and Responsible AI

- [Towards Understanding Unsafe Video Generation](https://www.ndss-symposium.org/ndss-paper/towards-understanding-unsafe-video-generation/)
  - **Research question:** How does “Towards Understanding Unsafe Video Generation” evaluate or improve AI safety, alignment, oversight, or responsible deployment?
  - **What they did:** After filtering out duplicates and poorly generated content, the authors created an initial set of $2112$ unsafe videos from an original pool of $5607$ videos.
- [Understanding Data Importance in Machine Learning Attacks: Does Valuable Data Pose Greater Harm?](https://www.ndss-symposium.org/ndss-paper/understanding-data-importance-in-machine-learning-attacks-does-valuable-data-pose-greater-harm/)
  - **Research question:** How does “Understanding Data Importance in Machine Learning Attacks: Does Valuable Data Pose Greater Harm?” evaluate or improve AI safety, alignment, oversight, or responsible deployment?
  - **What they did:** The authors investigate the relationship between data importance and machine learning attacks by analyzing five distinct attack types.
