## File Organization

Each conference directory contains an index and one Markdown file per year:

```text
papers/<Category>/<Conference>/README.md
papers/<Category>/<Conference>/<Year>.md
```

Use the following columns for yearly paper lists:

```markdown
| Paper | Authors | Topics | Links |
| ----- | ------- | ------ | ----- |
```
